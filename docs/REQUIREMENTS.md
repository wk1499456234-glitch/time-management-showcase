# 要件定義書

## 目的と利用者

TimeWeaveは、学習や開発などに取り組む人が「どれだけ時間を使い、実際に何をしたか」を残し、自分の行動を振り返るための製品である。時間と成果を一緒に確認できること、行動量と習得度を混同しないことを重視する。

基本の流れは「活動を選ぶ → 時間を測る → 成果を文章で残す → 記録・集計を確認する → 根拠を見ながら一週間を振り返る」とする。記録の意味は[記録・集計定義書](RECORD-DEFINITION.md)、仕組みは[設計書](DESIGN.md)に定める。

## 機能と優先順位

| 優先度 | 機能 | 要求 |
| --- | --- | --- |
| 最優先 | 時間と入力内容を失わないこと | 一つの活動を開始・一時停止・再開・終了し、複数の原文を保存する。保存失敗で入力を失わず、再試行で重複を作らない |
| 高 | 成果の整理と確認 | 内容・数量・単位・分類を原文の根拠と結び付ける。人が修正でき、新しい正式分類は明示的に確認する |
| 高 | 記録の閲覧と週の振り返り | 有効時間と成果を集計し、前週と前4週平均を区別する。説明・提案には根拠と判断の限界を示す |
| 高 | 継続して使えること | 計測状態と保存済み記録を復元する。日本語・中国語、四ページの移動、バックアップを提供する |

同時に時間を測る活動は一つとする。本書で扱う製品の範囲は時間と成果の記録、週の振り返りであり、月・四半期・年の分析、予算設定、活動候補の管理は含めない。

## 現在の公開URLの実行環境

公開URLでは、用意された活動から選んで時間を測り、成果を文章で保存・編集する。記録はブラウザーに保存し、JSONファイルとして書き出し・読み込みできる。AI振り返りでは架空の五週間の集計と保存済みの結果を閲覧し、自分の試用記録とは分けて表示する。

新しい記録をAIで整理し、その内容や分類を確認・修正して、自分の振り返りを作成・更新するには、記録の保存とAI処理を行うサーバーへ接続する。これらはAIの利用が許可・設定された環境で使う機能である。下表の該当する条件はその環境に適用し、現在の公開URLから新たな生成を行えるという意味ではない。

## 主要な操作と受け入れ条件

| 場面 | 操作 | 条件 |
| --- | --- | --- |
| 記録を始める | 活動を選び開始する | 時間が進み、一時停止を有効時間から除く。再読み込み後も計測状態を復元する |
| 成果を残す | 計測中に入力して保存する | 空白だけの入力は拒否する。入力した空白・改行は保持する。保存失敗で入力を消さない |
| 原文を直す | 活動を開き原文を編集する | 原文の識別子と記録時刻を保持する。保存失敗で編集を閉じず、再試行で重複を作らない |
| 成果を整理する | 原文を保存した後にAIで整理する | AIの処理に失敗しても原文や時間の記録を失わない。遅れて届いた結果で新しい原文や人の修正を上書きしない |
| 成果を確認する | 内容・数量・単位・分類を確認し保存する | 数量のない成果を許容する。新しい正式分類を本人の確認なしで確定しない |
| 週を振り返る | 週を選び統計・比較・根拠を見る | 選択週に対応するデータを表示する。原文、整理成果、統計とAI説明を区別できる |
| AI説明を利用する | 生成・更新する、または保存済み結果を開く | 生成は本人の操作で行う。読み込みで再生成しない。関連データの変更を示し、更新失敗時にも前の結果を読める |
| バックアップする | JSONを書き出し、読み込む | 件数のプレビュー後に明示実行する。同一記録は一度だけ取り込み、矛盾は拒否する |
| 別の画面へ移る | ナビゲーション、戻る・進む、直通リンクを使う | 計測と入力中の草稿を維持する。旧バックアップリンクも対象を開いてフォーカスする |
| スマートフォンで読む | 記録・根拠・履歴を展開する | 文字を縮小せずに読める。週比較は日付と指標をまとめて表示する |

これらは製品が満たすべき条件であり、すべての実行環境で検証済みという意味ではない。実際に確認した版・環境・結果と検証の範囲は[検証記録](VALIDATION.md)に記載する。

## 判断とデータの制約

- 計画量・未完了量と、実際に完了した量を分ける。復習量を習得量、解答量を正解数とみなさない。
- 数量のない成果を許容し、異なる種類や単位を一つの合計にしない。成果ごとの所要時間や統一の効率スコアを推定しない。
- 未解析・未確認・不足している記録を成果ゼロで補わない。予算がなければ予算達成率を出さない。
- 保存できない場合は警告と再試行・書き出しを優先する。
- 固定例は閲覧用のデータとして区別し、新しい入力の分析に見せかけない。結果のない週へ別の週の説明を流用しない。
- AI説明は判断材料である。前提が足りないときは判断を留保し、提案は最大2件とする。
