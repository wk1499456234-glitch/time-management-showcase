# TimeWeave

[在线体验](https://wk1499456234-glitch.github.io/time-management-showcase/) · [日本語](README.md)

把投入的时间与 Output（做了什么、完成多少）一起保存，根据记录回顾自己的活动。

## 使用方法

1. 在[计时](https://wk1499456234-glitch.github.io/time-management-showcase/#/timer)选择活动并开始。支持暂停、恢复、结束并保存；暂停时间不计入有效时间。
2. 活动期间填写 Output，点击“保存成果”。保留原文、换行和空白；没有数量的理解、整理或感想也可以记录。
3. 在[记录](https://wk1499456234-glitch.github.io/time-management-showcase/#/records)选择“示例记录”或“当前浏览器试用记录”。展开活动可查看原文、内容、数量、单位与依据。试用原文可编辑；固定示例只读。
4. 在[回顾](https://wk1499456234-glitch.github.io/time-management-showcase/#/review)选择示例周，先看程序统计，再打开“五周统计与前四周均值”及成果变化旁的“查看依据”。手机按周显示指标，桌面显示比较表。
5. 在[设置](https://wk1499456234-glitch.github.io/time-management-showcase/#/settings)切换语言、导出试用记录 JSON 或预览导入备份。

## 固定示例与 AI

示例是2026年10月12日至11月15日五周、30次**虚构学习记录**，每周有效时间180分钟。27条成果为预置背景，不称为 AI 输出；11月9至11日的3条经过真实 AI 解析和人工类型确认，可展开查看 AI 原结果与确认说明。

目标周11月9至15日的回顾是真实模型生成后保存的日文原文。中文界面也明确保留日文，不冒充新的翻译调用。其他周没有已保存的 AI 回顾。打开、刷新、切换语言和查看结果均不调用 AI。**访客新输入只保存在自己的浏览器，不解析，也不会套用固定示例回顾。**

本机版支持原文先保存，再异步解析；用户可以修正内容、数量、单位，并确认新的正式成果类型。解析失败不影响原文。周回顾由用户主动生成或更新，已有结果保存重读，相关数据变化后标记过期。

## 如何理解统计和建议

有效时间由程序根据开始、结束与暂停计算；成果按类型与兼容单位分别汇总。不推算每条 Output 的专属耗时，也没有统一效率分数。统计采用 Asia/Tokyo，周一开始。

复习量不等于掌握量，作答量不等于答对量；定性成果可以没有数量，待解析不等于零成果。示例缺少目标、时间预算、难度、正确题数及成绩，因此不能据此判断目标达成率、正确率、掌握程度或学习效率。

AI 解释与最多两条建议仅供回顾，历史数量不自动成为下一周目标。此次模型正文主要比较前一周；前周数量对比与前四周均值由程序分别计算。展开“查看已保存的AI全文”和“建议理由（AI原文）”仍可阅读保存时的文字。

## 保存位置与版本区别

| 能力 | 公开展示版 | 本机版 |
| --- | --- | --- |
| 计时与 Output 原文 | 当前访客浏览器 | 电脑上的 SQLite |
| 新解析、修正、类型确认 | 查看固定真实示例，不调用新解析 | 保存后解析，用户修正与确认 |
| 周统计与 AI 回顾 | 固定五周统计及已保存日文回顾 | 根据实际记录统计，主动生成与更新 |
| JSON 备份 | 访客原始记录 | 原始记录 |
| SQLite 完整备份 | 不提供 | 包含原始记录、派生成果及回顾 |

沿用旧公开版浏览器存储，不清除原数据、不合并固定示例。没有跨浏览器或设备同步，清理浏览器数据前请导出 JSON。导入先预览，再合并；完全相同的记录不重复导入，冲突会拒绝处理。
