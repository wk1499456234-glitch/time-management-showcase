# 要件定義書

## 目的と利用者

学習や開発などに取り組む人が、「どれだけ時間を使い、実際に何をしたか」を残して振り返る。作者自身の利用場面を出発点とし、行動量と習得度を混同しないことを重視する。

公開デモでは、初めて使う人が計時と成果記録を試し、固定例でAIによる整理と振り返りの読み方を理解できることを目標とする。フル版では、許可された利用者が自分の記録を保存・解析し、必要なときに週を振り返る。

本書は現在の公開版を基準とする。別環境のフル版と未接続の計画を、公開版の実装済み機能として扱わない。記録の意味は[記録・集計定義書](RECORD-DEFINITION.md)、実装構造は[設計書](DESIGN.md)を参照する。

## 範囲と優先順位

| 優先度 | 公開版で実装済み | フル版で別途実装済み | 今後の確認・接続 |
| --- | --- | --- | --- |
| 最優先：記録の保全 | 単一活動の開始・一時停止・再開・終了、原文保存・編集、再読み込み、保存失敗時の再試行、複数タブの衝突保護 | サーバー保存、原文の版管理、アカウント別のデータ分離 | 組織の保存先・保持期間・運用責任 |
| 高：成果の理解 | 固定例の原文、整理成果、数量、単位、確認内容を閲覧 | 非同期AI解析、手動修正、新しい正式分類の明示確認 | 組織のモデル利用権限、費用負担 |
| 高：振り返り | 固定5週の統計、前週比較、前4週平均、保存済み日本語AI結果と根拠 | 自分の記録の週統計、操作によるAI生成・更新、保存結果の再利用と更新必要表示 | 組織認証やAI基盤への接続検証 |
| 高：継続利用 | 日本語・中国語、四ページの直通リンク、JSONの書き出し・読み込み | ログイン、原始記録JSON、管理者の完全バックアップ | 実機での残りの操作確認 |

公開版は固定の活動候補を使い、同時に計測する活動は一つ。訪問者の新しい入力にAI解析や週振り返りを適用しない。月・四半期・年の分析、予算の設定、活動管理、一般公開されたフル版サービスは本公開版の機能に含めない。

## 主要な操作と受け入れ条件

| 場面 | 操作 | 条件 |
| --- | --- | --- |
| 記録を始める | 活動を選び開始する | 時間が進み、一時停止を有効時間から除く。再読み込み後も計測状態を復元する |
| 成果を残す | 計測中に入力して保存する | 空白だけの入力は拒否する。入力した空白・改行は保持する。保存失敗で入力を消さない |
| 原文を直す | 自分の活動を開き原文を編集する | 原文の識別子と記録時刻を保持する。保存失敗で編集を閉じず、再試行で重複を作らない |
| 固定例を理解する | 記録の表示元をサンプルに切り替える | 自分の記録と混ざらず、AIの元の解析と人の確認内容を区別できる |
| 週を振り返る | 週を選び比較と根拠を開く | 選択週に対応する統計を表示する。AI結果のない週で別の週の文章を流用しない |
| バックアップする | 設定からJSONを書き出し、読み込む | 件数のプレビュー後に明示実行。同一記録は一度だけ取り込み、矛盾は拒否する |
| 別の画面へ移る | ナビゲーション、戻る・進む、直通リンクを使う | 計測と入力中の草稿を維持する。旧バックアップリンクも対象を開いてフォーカスする |
| スマートフォンで読む | 記録・根拠・履歴を展開する | 文字を縮小せずに読める。週比較は日付と指標をまとめて表示する |

これらは受け入れ条件であり、すべての端末で検証済みという意味ではない。バージョン別の実績と未実施項目は[検証記録](VALIDATION.md)に分けて記載する。

## 判断とデータの制約

- 計画量・未完了量と、実際に完了した量を分ける。復習量を習得量、解答量を正解数とみなさない。
- 数量のない成果を許容し、異なる種類や単位を一つの合計にしない。成果ごとの所要時間や統一の効率スコアを推定しない。
- 未解析・未確認・不足している記録を成果ゼロで補わない。予算がなければ予算達成率を出さない。
- 公開版の保存先はブラウザーであり、自動同期・サーバー復旧はない。保存できない場合は警告と再試行・書き出しを優先する。
- 保存済みのAI説明は判断材料である。前提が足りないときは留保し、提案は最大2件とする。

## 未完了事項

JSON読み込み画面のファイル選択から完了までのブラウザー再検証、実機iPhone/Safariの残りの操作、ソフトキーボードと安全領域は継続確認する。プログラム層のテスト合格とは分ける。

会社環境を利用する場合は、認証、データ保存、AIインターフェース、費用負担、バックアップ・復旧を確認する。既存バックエンドへの互換性や会社向け接続はまだ検証済みではない。
